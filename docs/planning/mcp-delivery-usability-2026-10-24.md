## 范围与实机证据

原生 Wails 当前在 `/profiles/:slug/deliveries/mcp` 运行，屏幕约 1239×851。只读实机截图保存在本次审计机器的 `/tmp/mender-ux-20261024/02-native-before.png`（不纳入仓库）。已确认：单条服务记录仍展示搜索框，行内有两个无可见文字的复制按钮和两个高影响图标按钮；“停止”直接执行。代码位置：`packages/app/src/domains/servers/servers-page.tsx`。

目标：新用户能一眼识别复制连接地址，不误触断开服务；熟练用户仍可复制客户端配置、重启与停止；不增加新状态机、不改后端。

## 本轮行为契约

1. **一行一个常用主操作**：清晰标识“复制端点”，结果有即时反馈；配置复制、重启、停止集中到有文字的“更多操作”，不是仅依赖图标。
2. **明确破坏性操作**：“停止”先展示目标端点、与客户端断连后果；若关联 Tunnel，同时说明停止关联隧道；取消不应调用原生服务。
3. **隐藏不必要的密度**：开始时间仍可在更多操作中查看，但不占常驻列；少量服务时不展示无必要搜索，超过阈值或正在筛选时仍可搜索。
4. **守住边界**：Profile 过滤仍在原有组件内生效；所有原有 `start/restart/stop/list` Client API 不变；服务生命周期轮询及陈旧快照防护不变。
5. **失败与权限**：复制失败继续显示错误；执行中禁用操作；取消不会发送网络请求；不调用真实生产服务的停止/重启验证。
6. **验收**：英文、中文可见文字、按钮可访问名称、键盘可达、打开菜单后可找到全部原功能、取消与确认、低/高服务数量、与原生 Wails 视图一致；运行类型检查、相关测试和 Web 构建。仅通过测试不宣称完整 WCAG 合规。

## 边界外

本轮不重构全局导航，不修改 Profile 供应判定、Agent 任务状态、Tunnel 与审批逻辑。其他页面待逐页截图与任务流程审计后另行治理，不能以本页完成代表全应用完成。
