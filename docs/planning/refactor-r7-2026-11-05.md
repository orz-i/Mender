R7 removes the obsolete Provider catalog projection wrapper, the Bootstrap
aliases for the management source-owner and local Profile CLI types, and the
private Workspace Tool request aliases. The canonical implementations
remain. The empty Go import exception file and loader are retired after R3
removed the last three temporary edges. The existing architecture gate still
checks platform-specific production sources and rejects forbidden imports.
Reviewed cross-table read projections and atomic reference guards retain
their separate persistence ownership.

The private TypeScript SDK now exports `ManagementClient` as the single
common contract. All app consumers and fixtures use it directly. The MCP
server panel lives in Profile delivery and uses that page's Profile snapshot.
The old cross-Profile selector and duplicate Profile inventory read are gone.
Polling depends on the current Profile's Tunnel instances. The old
`/servers` bookmark redirects to Profiles.

HTTP, CLI, Wails and plugin wire contracts are preserved. Runtime and Agent
entry facades still serve active adapters, and historical SQLite migrations
remain the upgrade path for supported databases.

## Real environment acceptance

The Windows run uses automated fixtures. It does not attest to a current
native WebView session, an external account, or a remote execution host.
Wails, Docker, SSH and Agent CLIs may be installed even when their required
toolchains, accounts, target settings or model entitlements are unavailable.
The opt-in Docker, SSH, Daytona and real ACP settings were absent in the
verification environment. Use a disposable database and resource roots for
each acceptance run, and record the revision, platform, prerequisite and
observed result. Keep secret values and unredacted child logs out of receipts.
