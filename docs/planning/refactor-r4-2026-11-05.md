## Migration and acceptance

| Stage | Responsibility migration | Acceptance |
| --- | --- | --- |
| Shared boundary | Typed operation data, consuming ports, shared defaults and lease cleanup | No JSON/Outcome in Workspace domain/application; cleanup errors retain precedence |
| Local | Filesystem/process operations consume typed requests | Preserve os.Root, symlink checks, isolation, atomic writes and existing assertions |
| Docker | Typed container file/process operations | Preserve digest fencing, staged writes, health gate, bounded output and uncertain cleanup |
| Daytona | Typed remote operations | Preserve restrictive paths, SDK behavior, search bounds and timeout/output differences |
| SSH | Typed SFTP/process operations | Preserve pinned connection, cancellation, exclusive writes, rename and retained uncertain lease |
| External | Typed host codec around unchanged v1 RPC | Real example plugin roundtrip; malformed/oversized result, process exit and cleanup checks |
| Completion | Delete temporary adapter and old JSON WorkspaceSession | All drivers use typed ports; architecture gate prevents regression; necessary checks pass |

Built-in defaults are read offset 1/limit 200, search path `.`/maximum 100,
replace expected count 1, and shell cwd `.`/timeout 30000 ms. External v1 retains
omitted defaults on its wire. Search text presence is explicit to preserve empty
Daytona content matches and omitted empty Local/Docker/SSH snippets.

Optional request fields also retain explicit false, empty strings and empty edit
arrays through typed presence bits. External results carry their host-measured
original trimmed byte count, rather than raw JSON, through the application.
Requests retain their post-alias source byte count for the same reason: HTML or
Unicode escaping during v1 encoding must not turn an originally permitted Edit
payload into a new argument-limit failure. Unmeasured direct typed callers
continue to use their encoded size; the original source limit is always checked
before Tool decoding.
Invocation's internal Outcome size metadata preserves the existing v1 byte
measurement even when typed JSON encoding becomes shorter or longer. The
existing budget snapshot's result limit is copied into ExecutionRequest only
to preserve size-before-schema precedence for invalid external results.

Typed data crosses this boundary; Tool JSON decoding and Invocation result/error
mapping live in the Workspace Tool adapter. Driver-specific resource bounds,
error sanitization and cleanup stay with the backend. The bridge retains SSH
and External argument byte limits before decoding. Target aliases and reviewed
facts remain checked before any backend acquisition.

## Environment and remaining limits

- Docker portable SessionAPI tests and Linux compile-only checks cover the
  changed operation/Unix fixture code. Real Docker integration requires a
  non-Windows host plus `MENDER_DOCKER_TEST_SOCKET` and an immutable-digest
  `MENDER_DOCKER_TEST_IMAGE`; these are not configured here.
- Daytona fake-client tests cover the typed boundary. Real account operations
  require `MENDER_DAYTONA_LIVE_KEY`; billable creation additionally requires
  `MENDER_DAYTONA_LIVE_CREATE=yes`. No remote resource was created.
- SSH verification uses the existing local authenticated SSH/SFTP fixture and
  Runtime admission/lifecycle integration. It does not validate a production
  remote Linux host, shell or systemd service.
- Local symlink assertions keep the repository's explicit skip when Windows
  cannot create the fixture symlink. They are not treated as live path-security
  proof on an untested platform.
- External v1 remains untrusted. Typed numeric result fields must fit the
  corresponding Go int/int64; out-of-range values fail closed as invalid
  results. The codec retains the old validator's float64 integer semantics
  within that representable range and parses extreme exponents in bounded
  space/time.
- Web/Desktop builds retain the pre-existing Vite advisory for chunks above
  500 kB. No frontend splitting or later refactor phase is included in R4.
